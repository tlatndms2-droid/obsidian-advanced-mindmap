# 0.4.9 연결 카드 정렬 시험

사용자 승인한 방향 유지·기준 카드 고정·겹침 해소·한 번의 Undo를 시험 기능으로 구현.

- Ctrl+Shift+L / 명령 팔레트 `연결된 카드 정렬 (시험)`.
- 직접 연결된 카드만 대상, 연결 방향(화살표의 출발/도착)에 무관.
- 현재 카드 중심의 상대 위치로 사방 분류. 각 방향에서 기존 순서를 유지하고 설정 간격으로 배치.
- 카드 크기/내용/연결/기준 카드/무관한 카드 유지.
- 고정 카드에 막히면 해당 방향 행/열을 바깥으로 이동. Group은 정렬·충돌 대상에서 제외.
- 편집 중 비활성. 전체 위치 변경은 한 번의 Undo/Redo.

검증: 타입 검사·빌드, 크기/배치가 다른 50개 자동 사례의 겹침·고정 카드·원본 불변·연결 보존 검사 통과.
Windows Obsidian 1.14.4 격리 Sandbox에서 실제 Ctrl+Shift+L 입력, 연결 카드 정렬, 기준/무관한 카드 유지, 겹침 없음, 한 번의 Undo 및 Redo 확인. 실제 정렬 화면 캡처 확인. 재시작 후 0.4.9에서 같은 검사 통과.
Sandbox 등록 단축키에서 Ctrl+Shift+L의 다른 명령 충돌 없음 확인. 다른 Vault의 사용자 설정까지 보장하지 않음.
