# 0.3.1 사용자 피드백 검증

2026-10-20, Windows / Obsidian 1.14.4의 기존 격리 Sandbox에서 검사했다. 재시작 후 로드 버전 0.3.1을 확인했다.

| 초기 상태·입력 | 기대 및 실제 결과 | 결과 |
|---|---|---|
| 너비500 짧은 글 → Ctrl+Space 편집 종료 | 너비·높이 축소, Undo는 원래 크기와 작성된 글 보존 | 통과 |
| 너비500 긴 문단 → 편집 종료 | 너비500 유지, 줄바꿈에 맞춰 높이 축소 | 통과 |
| 이미 좁아진 카드에 긴 문단 입력 → 종료 | 너비 유지, 높이 증가 | 통과 |
| 기준 카드에서 두 번 방향 생성 | 각 신규 카드 선택·화면 중앙, Zoom 유지, 기존 카드 좌표 불변 | 통과 |
| 위 생성 뒤 Undo 두 번 및 Redo | 생성 직전 카드 순서대로 재선택, Redo 시 새 카드 선택 | 통과 |
| 연결 생성 Tab → Undo | 출발점 하나와 연결, 겹친 기존 카드 고정, 신규 카드·선 제거 및 기준 카드 재선택 | 통과 |
| 수동 크기 변경·교환·카드 삭제 각각 Undo | 원래 데이터와 카드 선택 복원 | 통과 |
| 무선택·화면 중앙 근처 카드 → Alt | 가까운 카드 선택 | 통과 |
| 오른쪽 Shift+W/A/S/D/Q/E | 네 방향 이동·줌 양방향, 왼쪽 Shift는 미적용 | 통과 |
| Ctrl+Space 진입 → 카메라 키 → Ctrl+Space 종료 | 확대·편집, 편집 중 카메라 키 차단, 종료 시 이전 배율 | 통과 |
| Ctrl 및 Tab 550ms 유지 | 기존 500ms 메뉴 표시. Tab 해제로 출발점만 저장하고 생성 안 함 | 통과 |
| 동일 Sandbox 재시작 | 0.3.1 로드, 주요 수정 검사 재실행 통과 | 통과 |

타입 검사, 빌드, 배치 단위 검사7개 통과. 검사 중 수집된 pageerror 없음.
사용자가 작성한 기존 Canvas는 백업과 바이트 일치를 확인했다. 기존 설정(500×100, Auto Resize OFF 포함)을 유지하고 원래 `Stage3-사용자확인.canvas`를 다시 열어뒀다.

증거: 로컬 `verification/artifacts/feedback-031/`의 runtime.json, extra.json, connected.json, restart.json 및 화면 PNG. 이 폴더는 gitignore 대상이다. 검사 스크립트는 `scripts/feedback-*.mjs`이며 테스트 전용 Canvas를 생성한다.

범위: 위 수정에 대한 검사다. 전체 제품 수용 테스트, 4~7단계, 타 버전·모바일·대량 성능 및 공개 Release는 수행하지 않았다. 실행 전부터 존재하던 Undo 이력이나 앱 재시작 이전 선택 이력까지 복원한다고 보장하지 않는다.
