# 파일 선택·교체 확인 — 현재 0.5.11

최신 기준: [5단계 동작](../planning/revised/STAGE5_CURRENT.md). 버전별로 폐기된 조작 안내는 이 문서에서 제거했다.

- [ ] 빈 텍스트 카드 또는 파일 카드 선택 → Alt+I → 파일 종류 선택.
- [ ] 문서/Canvas: 검색 → ↑↓ → Enter로 삽입/교체.
- [ ] 미디어: 네 방향키로 선택 → Enter로 즉시 삽입/교체.
- [ ] Ctrl+Enter로 미리보기 → 클릭 없이 재생 키 사용 → Ctrl+Enter로 목록 복귀. 카드가 삽입되지 않고 재생이 멈춰야 함.
- [ ] 생성일 묶음·생성일/수정일 정렬·검색·썸네일 크기·창 크기 조절.
- [ ] 취소 후 카드 불변. 교체 후 Ctrl+Z/Redo로 이전/새 파일·크기·연결 복원.
- [ ] 음악 → 영상 교체 시 과하게 작은 카드가 되지 않음. 이 크기 수정은 사용자가 확인했으며 다른 조합 검증과 구분.
- [ ] 내용 있는 텍스트 카드·편집 중·읽기 전용에서는 파일 교체를 실행하지 않음.
