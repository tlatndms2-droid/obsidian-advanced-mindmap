# 0.4.13 가까운 묶음은 평균 정렬, 먼 카드는 유지

최신 사용자 승인: 정렬 강도는 유지하되 먼 카드를 근거리 평균에 포함해 끌어당기지 않는다.

- 직접 연결 카드들을 기존 사방 방향별로 나눈 뒤 공간적으로 가까운 묶음으로 분리한다.
- 시험 근접 기준: 가장자리 거리 ≤ 2 × max(설정 gap, 해당 방향 카드 최대변 길이의 중간값). 인접한 카드들을 연결해 묶는다. 먼 카드 좌표는 거리 기준 산정에 쓰지 않는다.
- 각 묶음의 기준 쪽 테두리는 그 묶음의 평균 위치로 정렬. 카드 간격은 설정 gap으로 균등화하여 이전의 약한 간격 보정 대체.
- 먼 단독 카드의 위치는 유지. 멀리 있는 복수 카드도 자기 묶음 안에서만 정돈.
- 가까운 단독 카드는 기준 중심 정렬 유지. 실제 겹침은 개별 빈자리 이동으로 처리하므로 겹친 먼 카드까지 무조건 고정하는 기능은 아니다.
- 기준 카드·무관한 카드·내용·크기·연결 방향 유지. 연결 부착면 교정과 한 번의 Undo/Redo 유지.

## 검증

타입 검사·빌드 및 다양한 50개 배치 충돌 검사 통과.
원거리 카드 추가 전후 근거리 카드의 계산 결과 동일, 먼 카드 좌표 동일, 설정 간격 일치 확인.
Windows Obsidian 1.14.4 격리 Sandbox에서 실제 Ctrl+Shift+L:

- 가까운 3개 카드 테두리 평균 정렬과 설정 간격 일치.
- 먼 연결 카드·기준 카드·무관한 카드 좌표 동일.
- 연결 방향·색상·라벨 유지, 겹침 없음.
- 반복 입력 후 추가 이동 없음.
- Ctrl+Z 한 번으로 전체 원본 복원, Redo 복원.
- 재시작 후 0.4.13에서 동일 검사 통과. pageerror 없음.

Obsidian은 좌표를 정수로 저장하므로 평균 좌표 비교는 1px 이하 허용. 실제 전체 화면 캡처에서 근거리 3개 정렬과 원거리 카드 유지 확인.
근접 기준은 이번 시험 구현의 휴리스틱이며 모든 사용자의 묶음 의도를 자동 판별한다는 의미는 아니다.
