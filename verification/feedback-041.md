# 0.4.1 팔레트·Waypoint 사용자 검수 반영

- Ctrl+Shift+C 기본키, Ctrl+Alt+C 미작동. 변경 단축키 Ctrl+Alt+K도 실제 검사 후 사용자 지정값 변경 없이 제거.
- 선택 카드 아래8px 배치 확인. 방향키 강조·Enter 적용, 마우스 선택 유지.

- 색상 Undo, 편집 종료 시 진입전50% 복원 유지.
- 타입 검사·빌드 통과, 실제 Sandbox 재시작 후 위 동작 재검사 통과. 최종 오류 없음. 증거 verification/artifacts/feedback-041/.
