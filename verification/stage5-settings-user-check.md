# 설정 백업·복원 확인 — 0.5.11

설정창 값만 백업한다. 현재 기준은 [STAGE5_CURRENT.md](../planning/revised/STAGE5_CURRENT.md). 사용자에게서 설정 작업 후 진행 확인을 받았으나 아래 모든 예외 및 재시작 통과로 확대하지 않는다.

- [ ] 설정 → Canvas Mindmap → 설정 백업에서 새 JSON 저장.
- [ ] 설정값 하나 변경 → 복원 파일 선택 → 취소: 변경했던 값 유지.
- [ ] 다시 복원하고 승인: 백업 당시 값으로 복원.
- [ ] 관리창 크기·사용자 색상·Waypoint·연결 출발점·카드·연결 불변.
- [ ] 백업 복사본을 잘못된 JSON으로 바꾸고 복원: 오류 안내, 현재 값 유지.
- [ ] 재시작 후 복원한 설정 유지.

코드의 제외 항목/유효성 검사는 통과했다. Windows 파일창·저장 실패·재시작 실제 확인은 별개다. 과거 시험 당시 설정값을 현재 사용자 값으로 단정하지 않는다. 이전 관리창 크기 포함 백업은 현재 형식과 다르므로 새 백업으로 확인한다.
