## 대량 데이터 계산
Node 환경에서 탐색·생성·파일 전환·정렬·결과 검사를 묶어 각 10회 실행: 100개 14.10ms, 500개 19.73ms, 1,000개 35.54ms. 이번 코드 테스트 실행의 전체 시간이며 실제 Canvas 화면 갱신·디코딩·입력 지연·CPU/메모리 측정이 아니다. 사용자 PC 상태에 따라 수치는 달라진다.

## 미수행·남은 항목
- 실제 앱에서 결합 입력·Undo/Redo·선택·재시작·라이트/다크·좁은 창·대량 카드 반응: 사용자 확인 대기.
- 파일 이름 변경/이동/복제의 모든 경로 및 제거/재설치 보존(CM-120/125): 확인 대기. 현재 설정·사용자 색상 등은 플러그인 data.json에 저장되므로 설치 폴더 삭제 후 자동 복원은 보장하지 않는다. 이번 요청에서 저장 구조를 임의 변경하지 않았다.
- PDF 실제 렌더러·미디어 코덱·운영체제 파일 대화상자/저장 실패: 이번 코드 시험에서는 대체 객체 또는 순수 함수 범위. 실제 성공으로 보고하지 않는다.
- 전체 128개 요구사항/43개 수용 테스트를 현 버전에서 실제 재실행한 것이 아니다. 과거 결과는 역사적 증거로 유지하고 최신 UI 전체 통과로 승격하지 않았다.
- 생성 실패 알림에 한국어/영어 혼용 문구가 남아 있음을 코드에서 확인. 정상 동작 테스트 실패는 아니며 전체 한국어 안내 마무리 때 정리할 항목.
