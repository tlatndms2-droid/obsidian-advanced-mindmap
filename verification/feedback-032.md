# 0.3.2 검증

환경: Windows, Obsidian 1.14.4, 기존 격리 Canvas-Mindmap-Sandbox.

| 초기 상태와 입력 | 기대 및 확인 결과 |
|---|---|
| 가까운 대각선·먼 정방향 카드에서 Alt+↑ | 정방향 카드 우선 |
| 정방향 카드 제거 후 Alt+↑ | 대각선 카드 선택 |
| 다른 카드 선택 상태에서 Alt 단독 빠른 두 번 | 화면 중앙 근처 카드 선택. 느린 두 번은 기존 선택 유지 |
| 카드 선택 후 Shift+방향키 | 화면 이동, 기존 카드 좌표 불변. 초기 검사에서 발견한 기본 카드 이동 중복을 수정 후 재검사 |
| `]` 및 `[` | 확대 및 축소. 예전 오른쪽 Shift+WASD의 화면 이동 제거 |
| 기본 Shift+2와 Ctrl+Space 편집 진입 | 같은 목표 배율. 기본 애니메이션으로 목표에 수렴, 60개 프레임에서 확대 역행·100% 초과 없음 |
| 편집 중 `[]`, Shift+방향키 | 문자 입력·글 선택 유지, 카메라 단축키 미실행 |
| 설정 입력란에서 같은 입력 | 화면 이동·줌 미실행 |
| Follow editing line ON, 같은 줄 입력 | 가로·세로 카메라 목표 불변 |
| Enter로 다음 줄 입력 | 가로 목표·배율 유지, 입력 줄과 화면 세로 중앙 차이 3px 미만 |
| 직접 화면 이동 후 대기 → 다음 줄 입력 | 대기 중 화면 유지, 다음 줄 입력 시 따라가기 재개 |
| 설정의 토글 OFF → 여러 줄 입력 | 편집 확대 유지, 줄 따라가기 미실행 |
| 번호 등록 후 화면 이동·확대 | 30개 시점에서 번호 위치 오차 2px 미만, 화면 높이 22px 유지 |
| 기존 Ctrl 500ms·Ctrl+방향 생성·Undo·Ctrl+Shift 크기 조절 | 메뉴 표시·생성·기준 카드 선택 복원·크기 복원 유지 |

실행: 타입 검사, 빌드, 배치 테스트7개, 방향 우선/대각선 대체/후보 없음 단위 사례12개, 실제 Sandbox 입력 및 설정 조작.

증거: 로컬 `verification/artifacts/feedback-032/`의 runtime.json, extra.json, restart.json, 화면 PNG. scripts/feedback032-*.mjs는 새 시험 Canvas를 만들며 원래 사용자 Canvas는 수정하지 않는다. artifacts는 gitignore 대상이다.

검증 범위는 이번 수정과 관련 기존 동작이다. 다른 Obsidian 버전·모바일·전체 단계 수용 테스트·대규모 Canvas 성능은 포함하지 않는다. 모든 기기에서의 무프레임 저하를 보장하는 성능 측정은 아니다.
