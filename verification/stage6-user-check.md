# 6단계 사용자 확인 목록 — 0.5.11

실제 화면은 사용자가 확인한다. 코드 테스트 통과를 아래 항목의 통과로 대신하지 않는다. 이미 확인한 개별 기능을 재결정하는 목록이 아니라, 여러 기능을 함께 사용했을 때의 확인 목록이다. 기존 사용자 Canvas 대신 별도 시험 Canvas를 사용한다.

## 1. 생성·편집·탐색
- [ ] 빈 카드에서 Ctrl 0.5초 → 모드 선택 → Ctrl 해제. 일반/연결 생성에서 Ctrl+방향키와 짧은 Tab이 새 카드 선택·카메라 포커스를 제공하고 기존 카드를 밀지 않음.
- [ ] Tab 길게 → 출발점 선택 → 해제 시 카드 생성 없음. 다음 짧은 Tab은 저장한 출발점 사용.
- [ ] Alt+방향키: 바로 해당 방향의 카드 우선, 없을 때 승인한 대각선 후보. 무선택 Alt/Alt 두 번은 중앙 근처 카드 선택·포커스.
- [ ] Ctrl+Space 편집 → 설정 최소 배율 이상, 줄바꿈 세로 따라가기 → 종료 시 원래 배율. 편집 중 Shift+방향키/대괄호 화면 이동·줌 비활성.
- [ ] Ctrl+Shift+방향키는 편집 중에도 크기 조절. 길게 누른 한 작업은 Undo 한 번. Auto Resize는 편집 종료 때만, 짧은 글 너비 축소·긴 글 현재 너비 줄바꿈·빈 카드 기본 크기.

## 2. 연결·정렬·파일 교체·Undo 결합
- [ ] 연결된 카드 생성 → 파일로 교체 → 정렬 → X 삭제 → Ctrl+Z 반복 → Redo 반복. 각 작업의 카드/파일/크기/연결/선택이 순서대로 복원됨. Undo 후 새 작업하면 이전 Redo가 남지 않음.
- [ ] Ctrl+Shift+A+방향키는 대상 하나 연결, D 연결 해제, S 방향 전환. 편집 중 차단. 연결된 면과 선 방향이 의도 없이 바뀌지 않음.
- [ ] Ctrl+Shift+L: 근처 연결 카드 간격·정렬 정돈, 먼 카드 과도한 이동 없음, 연결 부착면 유지.
- [ ] Alt+I: 빈 텍스트/기존 파일만 대상. 문서·Canvas·이미지·PDF·영상·음악 간 교체 후 위치·연결 유지. 음악→영상 크기 수정은 사용자 확인됨; Undo로 이전 작은 음악 크기까지 복원되는지는 별도 확인.
- [ ] 파일 선택·미리보기 취소 후 원래 카드 불변. Enter는 삽입, Ctrl+Enter는 미리보기 열기/닫기.

## 3. 팝업·재생·키보드 간섭
- [ ] 미디어 목록에서 네 방향키는 선택만 이동. 배경 카드/카메라는 움직이지 않음. 검색·정렬·날짜 묶음·썸네일/창 크기 유지.
- [ ] 영상/음악 미리보기 열고 클릭 없이 Space/좌우 5초/상하 음량/M 사용. Ctrl+Enter/Esc/닫기 후 소리가 멈추고 목록 선택 복귀. 반복해서 열어도 중복 재생 없음.
- [ ] PDF·이미지 미리보기 및 목록 닫은 뒤 Canvas 단축키 정상 복귀.
- [ ] Ctrl+Shift+C 색상창 방향키·Enter는 색만 선택. Waypoint 관리창 Alt+W 방향키·Enter는 해당 항목 호출하고 창 유지. 이름/검색 입력 중 Canvas 키가 글자 입력을 방해하지 않음.

## 4. 저장·설정·파일 수명주기
- [ ] 카드 Waypoint는 현재 Zoom 유지·대상 선택, 카메라 Waypoint는 저장 Zoom 복원. 카드 삭제 Undo 후 배지·등록 복원. 다른 Canvas와 등록이 섞이지 않음.
- [ ] 설정 백업 → 값 하나 변경 → 복원 취소 시 변경값 유지 → 승인 시 백업값 복원. 관리창 크기·색상·Waypoint·카드/연결 불변.
- [ ] 손상/잘못된 형식 JSON 복원 시 오류와 기존 설정 유지. 원본 백업 대신 복사본으로 시험.
- [ ] Obsidian 재시작 후 설정·모드·Waypoint·사용자 색상·파일 카드 유지. 플러그인 비활성화 후에도 원본 파일·Canvas 데이터 유지.
- [ ] 별도 시험 Canvas의 이름 변경/이동/복제(Obsidian 및 Windows 파일 관리자) 후 Waypoint 대상과 원본/복제본 독립성 확인.
- [ ] 제거·재설치는 아직 보장하지 않음. 데이터 백업을 확보한 별도 시험 환경에서만 검증할 항목. 현재 설정·사용자 색상은 플러그인 저장 파일에 의존하므로 이를 삭제하는 제거 작업의 자동 복원은 코드 검사로 확인되지 않음.

## 5. 화면과 속도
- [ ] 라이트/다크·좁은 창에서 메뉴/선택 표시/스크롤/버튼 잘림 확인.
- [ ] 100/500/1,000개 시험 카드에서 생성·Alt 이동·정렬·Undo 시 지연/멈춤 확인. 코드 계산 시간과 실제 화면 반응은 다름.
- [ ] 이미지/PDF/영상 목록에서 연속 검색·미리보기·닫기 후 장시간 재생/로딩이 남지 않는지 확인.

## 결과 기록
문제가 있으면 `항목 번호 또는 제목 / 처음 상태 / 누른 키 / 기대한 결과 / 실제 결과 / 화면 또는 영상`으로 남긴다. 통과 항목만 체크한다. 전체 통과 전 7단계 Release·BRAT를 진행하지 않는다.
