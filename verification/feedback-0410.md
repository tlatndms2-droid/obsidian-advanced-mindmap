# 0.4.10 과도한 정렬 수정

영상 피드백과 사용자 승인에 따라 전체 행/열 재배치를 제거했다.

- 실제 카드 사각형이 겹친 경우만 이동한다. 설정 간격보다 가깝다는 이유만으로 이동하지 않는다.
- 현재 좌표 및 주변 카드 경계에 간격을 더한 후보 중 이동 거리가 짧은 빈자리를 고른다. 전체 배치의 수학적 전역 최적화를 보장하는 기능은 아니다.
- 기준 카드에 대한 기존 좌/우 또는 상/하 방향 유지.
- 다른 연결 카드들을 묶어서 밀지 않는다. 겹치지 않는 카드는 그대로 유지한다.
- 대상은 직접 연결된 카드. 카드 크기·내용·연결 및 무관한 카드 유지.

검증: 타입 검사·빌드, 50개 다양한 배치의 겹침 해소·원본 불변·고정 대상 유지 통과. 추가로 좁지만 겹치지 않는 배치 완전 동일, 재정렬 결과 동일 확인.

Windows Obsidian 1.14.4 격리 Sandbox에서 실제 Ctrl+Shift+L 입력 확인. 겹친 오른쪽 카드만 이동하고 왼쪽·위·아래·기준·무관한 카드 좌표 유지. 다시 실행해도 변화 없음. Ctrl+Z 한 번으로 원래 전체 배치 복원, Redo 복원. 실제 화면 캡처 확인. 재시작 후 0.4.10에서 동일 검사 통과.
