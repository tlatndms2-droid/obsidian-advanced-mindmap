# 0단계 — 개발 기반과 실제 Canvas 기술 시험

## 결과

**0단계 기술 시험 완료. 제품 기능 0/128, 제품 수용 테스트 실행 0/42.**

## 실행 환경과 제한

- 처음 실행된 앱 표시 버전은 1.12.7이었다. 재시작 후 1.14.4로 표시되어 현재 버전에서도 조작·제거·재설치 시험을 재실행했다.
- 현재 SDK 1.14.4에는 이번 Canvas 조작 메서드의 공개 타입 선언이 없다. 실제 앱의 내부 Canvas 기능 접근이 필요하므로 후속 단계는 호환성 확인을 거쳐 사용한다.
- 편집창은 Canvas 카드 안의 iframe에 있다. 후속 입력 상태·편집 종료 처리는 이 구조를 고려해야 한다.
- 기본 Undo 기록 최대값 100은 관찰값이다. 플러그인 고유 제한으로 만들지 않는다.
- 제거 후 보존은 `.canvas-mindmap-stage0-probe/metadata.json`의 시험 데이터로 확인했다. 이 경로는 검증용 후보이고 최종 제품 저장 경로 확정이 아니다.
- 실제 Waypoint·사용자 색상·설정의 저장/복원 구현과 전체 조합 검증은 후속 단계다. CM-120 전체 요구사항 통과로 표현하지 않는다.
- 생성 메뉴 최종 확정·닫기, 모드 유지, 기본 카드 크기, Tab 출발점은 아직 제품 구현 전 결정/대조 항목이다.
- 시험 카드 180×80 및 크기 변경 260×140은 고정 시험 입력이며 제품 기본 크기를 정한 것이 아니다.

## 재현·증거

Sandbox 전용 검사 스크립트 `scripts/stage0-probe.mjs`는 실제 Vault 경로를 확인한 뒤만 동작한다. `canvas`, `methods`, `state`, `transactions`, `storage`, `restart-check` 모드를 제공한다. `transactions`/`storage`는 Sandbox 시험 자료를 변경하므로 구현 단계의 검증 요청 범위에서만 실행한다.

로컬 증거는 `verification/artifacts/stage0/`에 있으며 Git에서는 제외한다. transactions.json·storage.json·restart.json과 실제 화면 PNG를 보관한다. 초기 workspace 및 시험 전 Canvas·플러그인 데이터를 별도 백업했다. Sandbox는 검토를 위해 열어 둔다.
