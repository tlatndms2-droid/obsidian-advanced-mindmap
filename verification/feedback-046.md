# 0.4.6 방향키로 가까운 카드 연결

사용자 확정: Ctrl+Shift+D를 누른 상태에서 방향키마다 해당 방향의 대상 카드 하나에 연결.

기존 Alt 방향 탐색의 직접 방향 우선·대각선 대안·가장자리 거리 기준을 재사용한다. 선택 카드를 출발점으로 연결하며 카드 선택·좌표·크기는 바꾸지 않는다. 같은 두 카드가 이미 연결돼 있거나 대상이 없으면 아무 변경도 하지 않는다. 방향키 자동 반복은 무시한다. 키를 놓거나 창 포커스·Canvas가 바뀌면 연결 대기를 해제한다. 편집/입력 중에는 실행하지 않는다.

## 검증 결과

Windows Obsidian 1.14.4, 기존 격리 Sandbox, 2026-10-20.

- 타입 검사 및 빌드 통과.
- 탐색 기준 단위 검사 12개 통과.
- 실제 Ctrl+Shift+D 유지 → 오른쪽: 가까운 카드 하나 연결, 더 먼 카드 제외.
- 같은 키 유지 → 위/아래: 각 방향 대상 하나씩 추가 연결.
- 같은 방향 재입력/키 자동 반복: 중복 연결 없음.
- 왼쪽 후보 없음: 변경 없음.
- 카드 좌표·크기·내용 및 원래 선택 유지.
- Ctrl+Z 한 번으로 마지막 연결 하나 제거, Redo 복원.
- D 해제 후 기존 Ctrl+Shift+방향키 크기 조절 유지.
- 편집 중 같은 조합 입력: 연결 없음.
- Sandbox 재시작 후 0.4.6에서 주요 검사 반복 통과.
- 검사 중 pageerror 없음. 연결된 실제 화면 캡처 확인.
