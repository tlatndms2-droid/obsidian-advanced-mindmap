# 0.4.14 승인 시안의 묶음 중앙 정렬

사용자 승인 HTML 시안: 기준 카드 고정, 가까운 묶음 전체 중앙을 기준 중앙에 맞추며 먼 카드 유지.

- 근거리 판정과 묶음 분리는 0.4.13 유지.
- 가까운 좌/우 묶음의 위끝~아래끝 중앙을 기준 카드 세로 중앙에 맞춘다.
- 가까운 위/아래 묶음의 왼끝~오른끝 중앙을 기준 카드 가로 중앙에 맞춘다.
- 먼 묶음은 기준 중앙으로 당기지 않는다.
- 크기가 다른 카드도 묶음 전체 경계 기준으로 계산한다. 가운데 카드 하나의 중앙을 맞추는 것이 아니다.
- 같은 간격, 기준 쪽 테두리, 연결 부착면 교정과 Undo/Redo 유지.

타입 검사·빌드, 기존 배치 검사 및 4방향 묶음 중앙 일치 검사 통과.
Windows Obsidian 1.14.4 실제 Sandbox에서 Ctrl+Shift+L 입력 후 가까운 3개 카드 전체 중앙=기준 중앙, 동일 간격, 기준/먼/무관 카드 좌표 유지 확인.
반복 입력 시 추가 변화 없음, Ctrl+Z 한 번으로 전체 복원, Redo 확인.
실제 화면 캡처를 승인 시안의 고정 카드/이동 묶음/중앙 관계와 비교했다.
재시작 후 0.4.14 동일 검사 통과, pageerror 없음.
