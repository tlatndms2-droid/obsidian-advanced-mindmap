# 0.5.15 Sandbox 확인

배포하지 않음. 2026-10-21 승인 단축키 변경만 반영.

## 코드 확인
- TypeScript 검사, 기존 9개 테스트 묶음, 빌드 통과.
- 기존 설정 백업 호환 검사 추가: autoResize boolean은 제거하고 나머지 설정 유지. 잘못된 값 거부.

## 실제 Sandbox
- Alt keydown에서는 선택 변화 없음. keyup 선택 해제/중앙 선택. Alt+방향키 keyup 선택 유지.
- Ctrl+Shift+Alt+오른쪽 두 번: 첫째 → 첫째+둘째 → 세 카드. Alt 전체 선택 해제.
- Shift+Alt+위/아래 배율 변경. ] 키로 배율 변화 없음.
- Ctrl+Shift+R: 짧은 글 100×50, 긴 글 기존 너비420 유지/높이482, 빈 카드 설정 기본500×100. 세 카드 선택 유지. Ctrl+Z 한 번에 원래 세 카드 크기 복원.
- 편집 중 Ctrl+Shift+R 변화 없음, 편집 종료 후 자동 조절 없음.
- Alt+M 기존 메뉴 표시, 방향키 강조, Enter 실제 선택 맞춤 실행. 검증용 하위 메뉴를 잠시 추가하여 오른쪽 진입, Esc 메뉴 개수2→1→0 확인. 임시 항목 제거.
- 설정창의 입력 줄 따라가기 OFF 후 줄 이동 시 카메라 유지, ON 후 다른 줄 이동 시 카메라 세로 이동. 설정값은 원래 ON으로 복원.
- 전체 Sandbox 재시작 후 같은 단축키·Undo·편집 차단·메뉴 실행 반복 통과.

## 사용자 확인
- Alt 단독 선택/해제와 Alt+방향키 탐색.
- 여러 카드 선택 확장 후 Ctrl+Shift+R 및 Ctrl+Z.
- Alt+M 메뉴의 방향키, Enter, Esc.
- Shift+Alt+위/아래 확대·축소와 입력 줄 따라가기 스위치.

원본 Vault, 공개 Release, BRAT은 변경하지 않음. 전체 제품 재검증이 아닌 이번 변경 관련 검사.
