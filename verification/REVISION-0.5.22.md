# 0.5.22 확정 수정사항 — Sandbox 검증, 미배포

## 최종 후속 변경 및 배포 승인

사용자 확인 후 0.5.22 전체 공개 배포 승인. 아래 미배포 문구는 검증 당시 상태.
최종 메뉴 동작은 편집 중 Alt+M → 실제 입력 편집기 우클릭 메뉴, 편집 밖 Alt+M → 카드 메뉴와 숫자 표시로 구분. 숫자는 메뉴를 닫으면 숨김. 색상 선택지는 방향키·Enter·Esc로 조작하며 카드 이동 차단. 다중 선택 native 정렬 메뉴도 지원.
최종 설치본 전체 재시작 후 5개 시나리오 통과: 표시/숨김, 색상 선택·적용 및 좌표 불변, 취소, 입력 편집기 메뉴·하위 메뉴 순차 닫기·커서 복귀, 다중 선택 정렬 메뉴 탐색 중 좌표 불변. 첨부 이미지와 실제 입력 편집기 메뉴 캡처 비교 완료.
증거: verification/artifacts/menu-0522/runtime.json, align.json, editor-menu.png, color-choice.png, final.json. 배포 직전 타입·10개 코드 검사와 설치파일3개 일치 재확인.

2026-10-23. 사용자 요청대로 공개 배포·push·BRAT 작업 없음.

## 반영
- Alt+R: 선택한 텍스트 카드 각각 내용 맞춤, 편집 중에도 커서·텍스트·편집 유지. 기존 빈 카드 기본 크기 및 너비 제한 유지.
- Tab: 바로 아래 생성 유지. 화살표 양방향의 직접 연결 카드만 출발점 후보로 사용. 저장된 출발점도 현재 카드와 직접 연결된 경우에만 재사용. 새 연결의 부착면은 상대 위치에 맞추며 기존 연결은 변경하지 않음.
- Tab 메뉴 방향키는 메뉴만 조작. Ctrl hold 500ms, Tab hold 200ms.
- 편집 중 Alt+M: native 카드 메뉴, 방향키·Enter·Esc 처리. 하위 메뉴 Esc 한 단계 닫기와 원래 입력 위치 복원.
- 다중 선택의 마지막 탐색 카드에 glow.
- 상단 숫자 1–9/0, Shift+1–9/0으로 툴바 1–20번째 실행, 번호 표시. 편집·입력·메뉴에서는 차단. 넘버패드 유지. 해당 슬롯이 있는 경우 native Shift+숫자 확대 명령의 중복 실행 차단.
- 그룹 탐색 추가는 취소 상태 유지.

## 검사
- 타입 검사, 기존 10개 테스트 묶음 및 추가 Tab 양방향 후보/부착면 회귀 테스트 통과.
- 실제 Sandbox에서 Tab 양방향 후보, 메뉴 조작 중 카드 좌표 불변, 아래 생성, 오른쪽 출발점의 왼쪽→새 카드 오른쪽 연결, 기존 연결 보존 확인.
- Ctrl 280ms 미표시/550ms 표시 및 Tab 260ms 표시 확인.
- 편집 중 Alt+R 크기 변경·커서·텍스트·편집 유지, 다중 카드 각각 맞춤 및 native Undo 크기 복원 확인.
- 편집 중 Alt+M native 메뉴 및 커서 복원, 실제 native 하위 메뉴에 임시 검증 항목을 추가해 방향키·Esc 두 단계 닫기 확인 후 임시 항목 제거.
- 기본 툴바 실제 색상 버튼 실행과 숫자 표시, 다중 선택 glow 캡처 확인. 기본 툴바는 4–5개이므로 1–20 전체 키 매핑은 임시 툴바 버튼으로 검증 후 원래 native 툴바 복원. Shift+숫자 실행 시 카메라 좌표·배율 불변 확인.
- 최종 빌드 설치 후 별도 Sandbox 프로세스를 종료하고 재시작하여 동일 검사를 다시 통과. 재시작 과정에서 설치된 Obsidian은 1.14.4에서 1.14.5로 전환됨. 최종 플러그인 0.5.22.
- 증거: verification/artifacts/revision-0522/runtime.json, extra.json, submenu.json 및 화면 PNG. 테스트는 별도 Canvas에서 수행.

Sandbox: Canvas-Mindmap-Sandbox, CDP 9267. 원본 Vault 변경 없음. 사용자 확인용으로 열어둠.
