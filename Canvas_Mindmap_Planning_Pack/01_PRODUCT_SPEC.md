# 01 — 제품 기능 명세

## 목적
Obsidian Canvas에서 키보드 중심으로 카드를 생성·배치·탐색·크기 조절하고, Waypoint와 색상 팔레트로 작업을 보조하는 Canvas Mindmap 플러그인.

## 기능 1 — 카드 생성·삽입
- 플러그인 설정의 기본 카드 크기를 모든 플러그인 카드 생성에 사용한다.
- 카드 생성 기본 간격: Canvas 좌표 기준 **100px**, 사용자 설정 변경 가능.
- 생성 직후 텍스트 편집 모드로 들어가지 않고 선택 상태 유지.
- `Ctrl + 방향키` 생성 시 대상 방향에 카드가 있으면 해당 방향으로 밀어낸다.
- 연속된 카드도 함께 밀어내고, 밀려나는 카드에 연결된 다른 카드도 연결 방향이나 연결 단계와 무관하게 함께 이동한다. 충돌이 연쇄되면 영향을 받는 카드들도 밀어낸다.
- 생성 기준 카드는 고정한다. 연결되지 않은 카드도 충돌/밀어내기 판정에서 별도로 예외 취급하지 않는다.
- `Tab` 삽입은 새 카드 아래 기존 카드의 공간이 부족할 때 이동시킨다. 충분한 빈 공간이 있으면 이동하지 않는다. 일부 부족하면 **부족한 거리만큼만** 이동한다. 기존 간격 유지, 신규 카드는 왼쪽 정렬.
- 생성 컨텍스트 메뉴의 일반 **생성**은 연결선을 만들지 않는다. **연결 생성**과 구별한다.
- 한 번의 `Ctrl + Z`로 신규 카드와 이에 따른 모든 카드 이동을 함께 취소한다.

## 기능 2 — 위치 교환
- `Ctrl + Alt + ↑/↓`: 단일 선택 카드만 대상으로 위/아래 카드와 **X·Y 전체 위치 교환**.
- 카드 연결 유무와 관계없이 적용. 두 카드 왼쪽 모서리 X좌표 차이가 설정 허용치 이내여야 한다. 기본 **40px**, 사용자 변경 가능.
- 후보가 여러 개면 입력 방향에서 세로로 가장 가까운 카드를 선택한다. 후보가 없으면 아무 동작도 하지 않으며 안내도 표시하지 않는다.
- 서로 크기가 달라도 카드 자체 크기를 유지하고 겹치지 않도록 순서를 재배치한다. 기존 카드 사이 간격을 유지한다.
- 카드 내용과 연결 대상은 변경하지 않는다. 연결선은 카드 이동에 따라 따라간다.
- `Ctrl + Z` 한 번으로 위치 교환 전체를 복원한다.

## 기능 3 — 수동 크기 조절
- `Ctrl + Shift + →`: 가로 확대, `←`: 가로 축소, `↓`: 세로 확대, `↑`: 세로 축소.
- 기본 변경 단위 **20px**, 설정에서 변경 가능.
- 단일 카드 선택에서만 실행. 왼쪽 위 모서리 고정.
- 다른 카드와 겹쳐도 허용하고 다른 카드를 밀지 않는다.
- 플러그인 별도 최소 크기를 두지 않고 Obsidian 기본 제한을 따른다(실제 제한 검증 필요).
- 키를 길게 누르면 연속 조절, 키를 놓으면 정지. 하나의 연속 키 누름을 `Ctrl + Z` 한 번으로 되돌린다.

## 기능 4 — Auto Resize
- ON/OFF 토글만 제공. 별도의 일회성 크기 맞춤 명령 없음.
- 기본 토글 단축키 `Ctrl + Shift + R`로 논의됨. Obsidian 단축키 설정에서 변경 가능하도록 요구.
- ON이면 텍스트 편집 종료 시 가로·세로를 **내용에 맞게** 조절한다. 텍스트 변경이 없더라도 편집 종료 시 실행.
- 입력 중에는 수동 변경 상태를 유지하고 **편집 종료 후** 적용.
- 왼쪽 위 모서리 고정. 겹쳐도 다른 카드 이동 없음. 다중 선택 카드 크기 맞춤은 각 카드 내용에 맞춰 개별 적용.
- ON으로 전환하는 순간 기존 카드들을 일괄 변경하지 않는다. 이후 편집 완료된 카드에만 적용.
- ON/OFF는 전체 Canvas 공유, 마지막 상태 저장 및 재시작 복원.
- Auto Resize 직후 Undo는 크기 변경만 먼저 취소하고 텍스트는 유지. ON 상태 유지, 다음 편집 종료 시 다시 적용.

## 기능 5 — 카드 탐색
- `Alt + 방향키`: 단일 선택 카드에서 해당 방향의 가장 가까운 카드로 선택 이동.
- 거리가 같으면 이동 방향 중심선에 더 가까운 카드 우선. Group은 탐색 대상 제외. 연결 여부는 무관.
- 대상이 없으면 선택 유지, 아무 동작 없음. 텍스트 편집 중/다중 선택 중 실행하지 않음.
- 화면 안에 이미 보이는 카드라도 선택 카드를 **화면 중앙에 배치**.
- **Zoom 변경 금지**. 사용자가 직접 맞춘 배율 유지. Shift+2 선택 맞춤 Zoom은 사용하지 않음.
- 부드러운 화면 이동: 기본 250ms, 사용자 설정 변경 가능. 이동 도중 새 탐색 입력 시 기존 애니메이션 중단 후 새 대상 방향으로 전환.
- 키를 길게 눌러도 탐색은 1회만 실행. 다음 탐색은 키를 놓았다 다시 눌러야 함.

## 기능 6 — Waypoint
- 두 종류: 카드 Waypoint(대상 카드의 **현재 위치** 추적, 화면 중앙 이동·현재 Zoom 유지), 카메라 Waypoint(저장한 Canvas 화면 위치와 Zoom 복원).
- Canvas별 독립 관리. 번호 공유, 번호당 한 종류의 Waypoint만 등록.
- 카드 등록·해제: `Ctrl + 숫자패드 1~9`; 카메라 등록·해제: `Ctrl + Shift + 숫자패드 1~9`; 이동: 숫자패드 1~9 단독.
- 같은 대상에서 동일 등록 단축키 재입력 시 해제. 다른 대상에서 같은 번호로 등록하면 기존 등록 정보를 제거하고 새 대상으로 **확인 없이 덮어쓰기**.
- 덮어쓰기 시 이전 사용자 지정 이름을 폐기하고 새 대상에 맞춰 이름 재생성.
- 등록 이름: 텍스트 카드 첫 줄, 빈 카드 `카드 N`, Markdown/이미지/Canvas 파일 카드는 파일명, 카메라는 `카메라 Waypoint N`. 등록 시 한 번만 자동 생성, 이후 원본 변경 시 이름 자동 갱신 없음.
- 카드 삭제 시 등록 자동 해제, 삭제 Undo로 카드 복원 시 Waypoint도 함께 복원.
- Canvas 파일 복제 시 Waypoint도 복제하며 복사본의 카드 참조는 복사본의 해당 카드로 연결. 이후 독립 관리.
- Canvas 파일 이름 변경·폴더 이동에도 Waypoint 유지.
- 재실행 후에도 Waypoint 영구 복원.
- 등록 카드의 왼쪽 위에 번호를 항상 표시. Canvas Zoom에 관계없이 번호 화면 크기 일정. 겹쳐도 위치 자동 조정하지 않음.
- Waypoint 신규 등록·덮어쓰기·해제·이름 변경은 Undo/Redo 지원.

## 기능 7 — Waypoint Manager
- 기본 토글 단축키 `Ctrl + Alt + W`, 사용자 변경 가능.
- Canvas 위 **작은 비모달 플로팅 팝업**, 현재 마우스 커서 근처에 열림. 화면 경계에 걸리면 전체가 보이도록 위치 조정.
- 팝업 외부 클릭 또는 동일 단축키 재입력으로 닫힘. Canvas 파일 전환 시 자동 닫힘.
- 팝업의 **외곽 테두리 및 네 모서리를 직접 드래그**하여 가로·세로 크기 변경. 마지막 크기를 저장하고 재실행/재열기 시 복원.
- 등록된 번호만 오름차순으로 표시. 목록이 많으면 최대 높이 내 내부 스크롤. 초기 크기는 사용자 제공 스크린샷의 소형 팝업 정도를 참고하되 고정 픽셀 치수는 확정하지 않음.
- 항목 클릭 시 해당 Waypoint로 이동하고 팝업 자동 닫힘.
- 사용자 지정 이름을 목록 안에서 바로 편집. Enter 저장, Esc 취소. 편집 중 바깥 클릭 시 변경 취소 후 닫힘.
- 목록 삭제 아이콘 클릭 시 확인 없이 **등록만** 즉시 해제. 원본 카드 삭제 금지.

## 기능 8 — 색상 팔레트
- 기본 단축키 `Ctrl + Alt + C`, 사용자 변경 가능.
- 커서 근처 팝업. 색상 선택 즉시 지원되는 모든 선택 Canvas Item에 적용하고 자동 닫힘. 다중 선택 지원.
- Obsidian 기본 색상 + 사용자 지정 색상 제공. 기본 색상 복원 전용 항목은 **추가하지 않음**.
- 사용자 지정 색상은 시각적 Color Picker로 선택, 별도 저장 버튼 없이 선택 즉시 팔레트에 저장. HEX 직접 입력 UI 제외.
- 사용자 지정 색상 중복 저장 방지. 모든 Canvas에서 목록 공유. 우클릭으로 저장 색상 삭제. 저장 색상 삭제 시 기존 카드에 적용된 색상 유지.
- Esc/바깥 클릭/같은 단축키로 팔레트 닫기. 색상 미선택 시 기존 카드 색상 유지.
- 다중 카드 일괄 색상 변경은 Ctrl+Z 한 번으로 각 카드의 기존 색상을 함께 복원.

## 기능 9 — Undo / Redo
- Undo `Ctrl + Z`, Redo `Ctrl + Shift + Z`.
- 작업별 역순 Undo, Redo는 반대 순서. Undo 후 새로운 작업을 실행하면 기존 Redo 기록 초기화.
- Canvas별 독립 기록. Obsidian 실행 중에만 유지하며 재실행 시 기록 초기화.
- 기록 개수는 Obsidian 기본 제한을 따르며 별도 플러그인 설정 없음.
- 카드 생성+밀어내기, 위치 교환, 다중 카드 색상 변경, 다중 카드 방향키 이동은 각각 **한 번의 작업**으로 취소.
- 키 길게 누른 연속 크기 조절 및 다중 카드 이동은 하나의 키 누름부터 해제까지 한 작업으로 취급.
- 다중 카드 이동 후 Undo 시 **선택 상태 유지 여부는 미확정**. 기존 Obsidian 기본 선택 동작을 우선 검증할 것.
- 일반 방향키의 카드 이동 자체는 Obsidian 기본 기능을 우선하며 중복 구현하지 않음.

## 기능 10 — Settings 백업
- Settings에 수동 백업·복원 기능 제공.
- **설정값만** 백업. Waypoint, 사용자 지정 색상 목록, Canvas/Markdown 원본, Undo/Redo 기록은 백업 대상 제외.
- 백업 저장 위치는 Windows 파일 저장창에서 사용자 직접 선택.
- 복원 시 설정 전체 교체. 사용자 확인창 표시 후 실행, 취소 시 기존 설정 유지.
- 파일 손상·유효성 오류 시 **복원 전체 중단**, 기존 설정 전부 유지. 부분 복원 금지. 실패 이유 안내.
- 플러그인 비활성화 후 재활성화 시 Waypoint·사용자 지정 색상·설정 유지. 완전 제거 후 재설치 시에도 보존 요구. 저장 경로 및 실제 제거 정책은 기술 검증 사항.
