# 03 — 수용 테스트 / Definition of Done

상태: 아래는 **실행할 테스트**이며, 아직 실행 성공을 의미하지 않는다.

| ID | 사용자 시나리오 | 관찰 가능한 완료조건 |
|---|---|---|
| T01 | 카드 생성, 대상 방향에 카드 없음 | 설정된 기본 크기/100px 간격으로 생성, 신규 카드 선택, 편집 모드 자동 진입 없음 |
| T02 | 카드 생성, 충돌 및 연결된 카드 다단계 | 기준 카드 고정, 충돌 카드·연결된 카드·연쇄 충돌 대상 이동, 연결 관계 유지 |
| T03 | T02 직후 Undo/Redo | Undo 1회로 생성·모든 이동 원복, Redo 1회로 동일 결과 복원 |
| T04 | Tab 삽입, 충분한 공간 | 기존 카드 이동 없이 삽입 |
| T05 | Tab 삽입, 공간 일부 부족 | 부족한 거리만큼만 밀고 기존 간격 유지 |
| T06 | 위치 교환 후보 2개 | X 허용 오차 40px 이내에서 세로로 가까운 후보와 X/Y 위치 교환 |
| T07 | 위치 교환 후보 없음 | 안내 없이 선택·위치 유지 |
| T08 | 위치 교환 Undo | Undo 1회로 두 카드 위치 원복, 내용/연결 관계 유지 |
| T09 | 단일 카드 크기 변경 | 방향별 가로·세로 ±20px, 왼쪽 위 좌표 고정, 겹침 허용 |
| T10 | 크기 조절 키 길게 누르기 | 연속 조절, 키 해제 후 정지, Undo 1회로 키 누르기 전 크기 복원 |
| T11 | Auto Resize ON 후 편집 종료 | 내용 변경 유무 무관하게 가로·세로 맞춤, 주변 카드 이동 없음 |
| T12 | Auto Resize Undo | 첫 Undo는 크기만 되돌리고 텍스트 유지, ON 상태 유지 |
| T13 | Alt 탐색 | 방향에서 가까운 카드 선택, 중앙 정렬, Zoom 불변, 250ms 기본 애니메이션 |
| T14 | 탐색 중 재입력 | 이전 애니메이션 중단 후 새 대상에 집중 |
| T15 | 탐색 키 길게 누르기/편집 중/다중 선택 | 연속 탐색하지 않음/편집 중 미작동/다중 선택 미작동 |
| T16 | Waypoint 등록·동일 대상 재입력·다른 대상 덮어쓰기 | 동일 대상 해제, 다른 대상 덮어쓰기, 기존 번호 배지 제거, 새 이름 생성 |
| T17 | Waypoint Undo/Redo | 등록·덮어쓰기·해제·이름 변경 모두 복원 가능 |
| T18 | 카드 이동 후 Waypoint 호출 | 등록 당시 좌표 아닌 카드 현재 위치로 이동, 현재 Zoom 유지 |
| T19 | 카메라 Waypoint 호출 | 저장한 화면 위치와 Zoom 복원 |
| T20 | Canvas 복제/rename/move | 복사본 Waypoint 독립, 원본 참조 유지, 이름 변경·폴더 이동 후 등록 유지 |
| T21 | 카드 삭제 후 Undo | 카드와 연결된 Waypoint 함께 복원 |
| T22 | Waypoint Manager | 커서 근처 열림, 화면 경계 조정, 외곽 테두리/모서리 크기 변경, 마지막 크기 복원 |
| T23 | Manager 이름 편집 | Enter 저장, Esc 취소, 외부 클릭 시 편집 취소·팝업 닫힘 |
| T24 | Manager 목록 클릭/삭제 | 클릭 시 이동 후 팝업 닫힘, 삭제 시 원본 카드 유지하고 등록만 해제 |
| T25 | 다중 색상 적용 | 모든 지원 Item에 적용, Undo 1회로 각 카드 원래 색상 복원 |
| T26 | 사용자 색상 저장/삭제 | 중복 없이 모든 Canvas 공유, 팔레트 색상 삭제해도 적용된 Canvas 색상 유지 |
| T27 | 설정 백업·복원 | 파일 저장 위치 선택, 설정만 백업, 확인 후 전체 설정 복원 |
| T28 | 손상된 백업 복원 | 실패 안내, 설정·Waypoint·팔레트·Canvas 모두 기존 상태 유지 |
| T29 | 비활성화·재활성화·재실행 | 저장 데이터 복원, Undo/Redo는 재실행 시 초기화 |
| T30 | 제거·재설치 | 별도 보존 데이터에서 Waypoint·팔레트·설정 복원 요구. 실제 가능성 검증 필수 |
| T31 | 대형 Canvas 반복 조작 | Pan/Zoom/Drag/다중 선택/연쇄 이동 중 원본 손상·누락·비정상 지연이 없는지 측정 및 기록 |
| T32 | Light/Dark 및 단축키 충돌 | 팝업 가독성·키보드 조작·기본 Obsidian 기능 충돌 확인 |

Critical/High 결함, 원본 데이터 손상, Undo 불일치, 설정 복원 중 부분 변경이 남아 있으면 완료로 처리하지 않는다.
