# 5단계 현재 기준 — 0.5.11

2026-10-20 사용자 확정 및 코드 반영 기준. 아래 내용은 이전 파일 선택 시안과 버전별 인계 기록보다 우선한다. 원본 팩·ZIP·과거 SVG는 보존하며 현행 화면 검증 증거로 취급하지 않는다.

## 설정 백업·복원
설정창의 10개 값만 JSON으로 백업한다: 생성 모드, 새 카드 너비/높이, 간격, 크기 조절 단위, 교환 허용 오차, Auto Resize, 화면 이동 시간, 입력 줄 따라가기, 편집 최소 확대율.
관리창 크기·Waypoint·사용자 색상·연결 출발점·Canvas·Markdown·Undo·Obsidian 자체 단축키 설정은 제외한다. 저장 위치는 Windows 파일창에서 선택한다. 복원은 확인 후 전체 적용하며 취소/손상 파일은 현재 설정을 유지한다. 저장 실패 시 현재 메모리 설정을 교체하지 않는다. 실제 파일창·재시작·저장 실패 시 디스크 보존은 사용자 확인과 구분해 기록한다.

## Alt+I 대상과 파일 종류
빈 텍스트 카드 또는 기존 파일 카드 하나를 선택하고 Alt+I. 내용 있는 텍스트 카드·Group·Link·편집 중·읽기 전용은 제외한다. 기존 파일 종류와 무관하게 다른 종류로 교체할 수 있다.
메뉴는 Markdown / Canvas / Image / PDF / Video / Audio. 문서·Canvas는 Obsidian 기본 검색 선택창 형식이다. 보관함 내 파일을 선택하며 외부 파일 복사/가져오기 기능은 아니다.

## 미디어 목록과 미리보기
- 생성일 기준 오늘 / 어제 / 이번 주 / 이번 달 / 이전으로 중복 없이 구분. 로컬 날짜, 월요일 주 시작. 해당 파일이 없는 묶음은 표시하지 않는다.
- 각 묶음 안에서 생성일/수정일 최신순·오래된순 정렬. 검색·썸네일 크기·창 테두리/모서리 크기 조절 지원.
- 네 방향키로 선택, Enter로 즉시 삽입/교체. Ctrl+Enter 또는 클릭은 미리보기.
- PDF는 첫 페이지 썸네일과 큰 첫 페이지, 이미지는 크게 표시. 영상·음악은 Ctrl+Enter로 열 때 재생 시작 시도.
- 미리보기 Ctrl+Enter/Esc/닫기 아이콘은 재생을 멈추고 목록 선택으로 복귀. 하단 ‘목록으로’·‘카드에 넣기’ 버튼 없음.
- 미리보기를 열면 클릭 없이 키 입력: Space 재생/일시정지, 좌우 5초, 상하 음량 5%, M 음소거. 영상·음악에만 적용.
- PDF 암호 입력·전체 페이지 탐색은 현재 범위에 없으며, 지원되지 않는 코덱/파일은 미리보기 오류 안내.

## 카드·데이터
ID·좌표·연결·색상·Waypoint를 보존한다. 일반 파일 교체는 기존 크기를 넘기되 Obsidian의 파일별 자동 표시 크기 처리가 적용될 수 있다. 영상은 음악의 작은 높이를 이어받지 않도록 기존 너비/설정 너비 중 큰 값과 그 너비의 9/16 이상 높이로 초기 공간을 확보한 뒤 실제 비율을 적용한다. 이후 수동 조절에 새 최소 크기 제한을 만들지 않는다.
선택 취소는 원래 카드를 유지한다. Undo/Redo는 이전/새 파일·크기·연결을 함께 복원해야 한다. 원본 파일 자체는 수정하거나 삭제하지 않는다. 코드 데이터 보존 검사와 실제 앱 Undo 검증은 별개다.
