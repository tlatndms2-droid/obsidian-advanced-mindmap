# 개발 준비 확인 상태

기존 A1~A9는 재질문 목록으로 사용하지 않는다. 최신 사용자 답변과 기술 검증은 [DEVELOPMENT_BASELINE.md](DEVELOPMENT_BASELINE.md)에 통합했다.

- 새 카드 최초 크기: Obsidian 기본값으로 플러그인 설정 초기화.
- 오른쪽 생성: 세로 가운데 정렬.
- 교환: 제3 카드와 겹쳐도 실행, 주변 이동 없음.
- Auto Resize: 너비 유지·내용 높이 조절을 우선 시험 적용.
- Alt 탐색: 카드 가장자리 거리 기준.
- 카드 Waypoint: 중앙·선택·Zoom 유지.
- 파일 전환: 취소 시 원래 카드 유지, Undo 시 원래 위치·크기·연결 복원.
- 생성·Tab 메뉴와 출발점 선택은 누적 확정 유지. 고정 예외·밀어내기 재결정 금지.

현재 사용자에게 남겨둔 일괄 선택 질문은 없다. 구현 제약을 확인하기 전에 새 미결정 항목을 만들지 않는다. 외형 디자인은 뒤로 미룬다. 기술 검증 7개 묶음은 제품 구현 후 수행하며 지금은 미수행이다.
