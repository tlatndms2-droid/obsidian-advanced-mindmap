# 사용자 검수 정정 — 0.3.1

2026-10-20 누적 피드백의 구현 기준. 이전 명세·HTML·SVG에서 아래와 다른 내용은 이 정정을 우선한다. 원본 팩과 이전 도식은 보존한다. 4단계 UI와 Release는 이번 범위가 아니다.

| 항목 | 확정 동작 |
|---|---|
| FB-01 Auto Resize | 편집 종료 시 현재 너비를 상한으로 사용한다. 짧은 내용은 너비를 줄이고, 긴 내용은 현재 너비에서 줄바꿈하며 높이를 맞춘다. 높이는 증가·감소 가능. 좌상단 고정, 주변 카드 미이동, Undo 시 텍스트 보존. |
| FB-02 생성 후 화면 | 새 카드를 선택하고 현재 Zoom을 유지한 채 화면 중앙으로 이동한다. 자동 편집 진입 없음. |
| FB-03 Undo 선택 | 작업의 Undo 스냅샷에 대응하는 선택을 복원한다. 연속 생성 후 Undo를 반복하면 새 카드가 제거되며 해당 생성 직전 카드가 다시 선택된다. Redo는 다시 생성된 카드를 선택한다. 선택 기록은 실행 중 Undo 기록에만 두고 Canvas 파일에는 추가하지 않는다. |
| FB-04 키보드 카메라 | 오른쪽 Shift+Q 축소, E 확대, W/A/S/D 위/왼쪽/아래/오른쪽 이동. 카드 편집 및 입력란에서는 작동하지 않는다. 왼쪽 Shift에는 적용하지 않는다. |
| FB-05 생성 밀어내기 제거 | Ctrl+방향키와 짧은 Tab 모두 기존 카드를 움직이지 않는다. 기존 생성 위치·정렬·설정 간격·연결 출발점 규칙은 유지한다. 겹침은 허용한다. CM-014~021의 밀어내기·동반 이동·공유 카드 예외는 더 이상 실행하지 않는다. |
| FB-06 Ctrl+Space | 편집 시작 시 해당 카드를 중앙에 확대해서 보여준다. 다시 누르면 편집 종료 후 진입 직전 확대율로 돌아온다. 이전 카메라 위치 복원은 추가하지 않는다. |
| FB-07 무선택 Alt | 아무 카드도 선택되지 않았을 때 Alt를 누르면 화면 중심과 카드 중심이 가장 가까운 카드 하나를 선택한다. Group 제외. 이 동작 자체는 카메라를 움직이지 않는다. |

## 현재 조절값

다음 숫자는 사용자가 별도로 확정한 디자인 값이 아닌 현재 구현값이다. 사용 후 조절 가능하다.

- 카메라 이동: 키 입력당 화면상 60px, 누르고 있으면 반복.
- 줌: 키 입력당 로그 Zoom 0.1 변화.
- 편집 확대: 화면 가로·세로의 80% 안에 들어오는 배율, 현재보다 축소하지 않음.
- 중앙 이동 시간은 기존 사용자 설정을 사용한다.

## 검사

실제 Sandbox 결과는 `../../verification/feedback-031.md`를 따른다.
과거 밀어내기 도식과 T02/T05/T31 등의 밀어내기 기대값은 현재 동작의 수용 기준으로 사용하지 않는다. 현재 생성 검사는 기존 카드 좌표 불변과 생성 카드·연결선·선택의 Undo/Redo를 검사한다.
