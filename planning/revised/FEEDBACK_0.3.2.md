# 0.3.4 설정 추가
편집 시 최소 확대율을 Minimum editing zoom에서 조절한다. 기본100%, 현재 배율이 높으면 유지. 줄 따라가기·종료 배율 복원은 유지한다.

> **0.3.3 정정:** 편집 진입 시 카드 크기에 맞추지 않고 `현재 배율과 100% 중 큰 값`을 사용한다. 50%→100%, 100%→100%, 150%→150%. 줄 따라가기 및 Ctrl+Space 종료 시 진입 전 배율 복원은 유지한다. 기존 Shift+2 배율 적용 설명보다 이 사용자 정정을 우선한다.

# 0.3.2 누적 사용자 검수 수정

2026-10-20. 이번 정정은 0.3.1의 기존 결정 위에 적용한다. 4단계 UI·중간 Release는 포함하지 않는다.

1. **Alt 방향 탐색:** 해당 방향에서 가로 또는 세로 범위가 겹치는 정방향 카드를 먼저 찾는다. 위·아래는 가로 범위 겹침, 좌·우는 세로 범위 겹침을 기준으로 한다. 정방향 후보가 없으면 해당 방향의 대각선 후보를 찾는다. 각 후보군 안에서는 기존 가장자리 거리 우선·동률 중심선 우선 규칙을 유지한다. 후보가 없으면 선택 유지. Group 제외, 편집 중 차단은 유지한다.
2. **Alt 빠르게 두 번:** 다른 카드가 선택돼 있어도 화면 중심에 가장 가까운 카드를 선택한다. Alt 단독으로만 판정하며 Alt+방향키 등 다른 조합은 제외한다. 무선택 Alt 한 번은 유지한다. 현재 구현값은 각 탭 유지 시간 및 탭 사이 간격 300ms 이내이며 사용자 고정 숫자값으로 간주하지 않는다.
3. **화면 이동:** Shift+방향키. Obsidian의 동일 키 기본 카드 이동과 중복 실행하지 않는다. 편집·검색·설정 입력 중에는 화면 이동을 하지 않고 글 선택을 보존한다. 기존 오른쪽 Shift+WASD의 플러그인 화면 이동은 제거한다.
4. **줌:** `[` 축소, `]` 확대. 오른쪽 Shift+Q/E 제거. 편집·입력란에서는 괄호 문자 입력을 보존한다.
5. **편집 확대와 줄 따라가기:** Obsidian Shift+2의 실제 `zoomToSelection`을 사용한다. 별도 큰 배율 계산을 제거하고 기본 Canvas 애니메이션만 사용한다. 편집기가 준비된 후 확대한다. Ctrl+Space 종료 시 편집 전 배율 복원은 유지한다.
   - 설정 **Follow editing line** ON/OFF 제공. 신규 설정 기본값은 ON으로 두어 검수 가능하게 하며 저장된 값은 존중한다.
   - ON은 편집 시작 때 커서가 있는 줄을 세로 중앙으로 맞춘다. 이후 같은 줄 입력에는 움직이지 않고, 자동 줄바꿈·Enter·다른 줄로 커서 이동 시 세로로만 따라간다.
   - 가로로 입력 커서를 추적하지 않는다. 줄 따라가기 중 배율·카드 좌표·크기는 변경하지 않는다.
   - 직접 휠 또는 가운데/오른쪽 버튼으로 화면을 조작하면 따라가기를 잠시 멈춘다. 다시 입력하거나 커서를 조작하면 줄 단위 따라가기를 재개한다.
   - OFF에서는 기본 편집 확대만 유지한다.
6. **Waypoint 배지:** Canvas의 실제 화면 변환·카드 스타일 갱신과 같은 화면 갱신 주기에 위치를 맞춘다. 기존 왼쪽 위 위치·화면상 고정 크기·등록 데이터·Undo는 유지한다.

원본 ZIP 및 과거 HTML·도식은 보존한다. 위와 다른 과거 단축키·가장자리 거리만으로 전체 후보를 고르는 설명·편집 시 최대 4배 확대 설명은 현재 기준이 아니다.
