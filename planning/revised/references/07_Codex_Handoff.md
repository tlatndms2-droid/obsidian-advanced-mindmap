# Codex Handoff
Codex에 넘길 때 구현자가 다시 기획하지 않도록 다음을 제공한다.

- 현재 목표
- MVP 범위
- 제외 범위
- 확정된 사용자 흐름
- UI 요구
- 데이터/상태 규칙
- Obsidian 통합 지점
- 오류/복구
- 성능 기준
- 테스트/완료조건
- 보류/미결정
- 공식 문서 확인이 필요한 항목

프로젝트에는 `HANDOFF.md`를 유지한다.

HANDOFF 권장 구조:
1. Current Goal
2. Current Version
3. Completed
4. In Progress
5. Decisions
6. Known Issues
7. Verification
8. Next Action
9. Do Not Change
10. Relevant Files

세션 종료 시 README/HANDOFF/버전 정보가 실제 코드·릴리즈 상태와 어긋나지 않는지 확인한다.
