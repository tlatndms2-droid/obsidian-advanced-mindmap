팩의 확정 동작디자인 제안 · 승인 전문서 안의 조작 예제
이 문서의 범위는 목록으로 합의한 15개 UI 화면·상태입니다. 전체 제품 요구사항 128개와 실제 Obsidian 수용 테스트 42개는 원본 팩이 기준입니다. 여기서 바꾸는 카드·설정은 예제 데이터입니다. 원본 Vault나 Obsidian 설정에는 적용되지 않습니다.

상단에서 라이트·다크를 전환할 수 있습니다. 각 항목의 검토 상태와 메모는 이 브라우저에 저장됩니다. 「검토 메모 저장」으로 별도 파일을 받을 수 있습니다.

아직 확정 화면에 넣지 않은 항목

  • 빈 카드 파일 전환·이미지 Panel (CM-126): 원본 검토 후 화면과 저장·Undo 흐름을 정해야 합니다.
  • Auto Resize 상태 표시: ON/OFF 동작은 확정됐지만, 별도 배지·토스트·버튼의 모양과 위치는 팩에 없습니다. 이 문서에서는 새 표시를 추가하지 않았습니다.
  • 단축키 변경 (CM-040·084·097·128): Obsidian 기본 단축키 설정을 이용합니다. 새 전용 단축키 창을 만들지 않았습니다.
  • 생성 메뉴의 최종 확정·닫기 방식과 모드 유지 기간: 새 팩에 상세 규칙이 없어 메뉴의 선택 강조까지만 시연합니다. Ctrl 해제로 확정하는 이전 대화 규칙을 가져오지 않았습니다.
  • 연결 생성 Tab 출발점 (CM-011): 재검토 항목입니다. 이 UI 문서에서 출발점을 임의로 확정하지 않습니다.

화면 제안의 승인과 실제 플러그인 동작 검증은 별도입니다. 승인 후 구현 화면을 이 시안과 비교하고, 원본 팩의 수용 테스트를 실제 Obsidian에서 확인합니다.
